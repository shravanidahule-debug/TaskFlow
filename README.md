# TaskFlow

A modern and responsive SaaS productivity landing page built using React and Bootstrap.

## Features
- Responsive navigation bar
- Hero section
- Features and About sections
- Pricing plans
- Login interface with form validation
- Smooth navigation between sections

## Technologies Used
- React.js
- Vite
- Bootstrap
- JavaScript
- CSS

## Installation

1. Clone the repository:
   git clone https://github.com/shravanidahule-debug/TaskFlow.git

2. Navigate to the project:
   cd TaskFlow

3. Install dependencies:
   npm install

4. Start development server:
   npm run dev

## Build

npm run build
